# 🗺️ Дорожная карта: Отладка и улучшения Crypto Exchange TMA

## Обзор проекта

Telegram Mini App для криптовалютного обмена, интегрированное с FixedFloat API.

**Текущий статус:** MVP готов, требуется отладка dev-режима и тестирование в Telegram.

---

## 📱 Core Screens Specification

### Screen 1: Главный экран обмена (EXCHANGE_FORM)
**ID:** `EXCHANGE_FORM`
**Статус:** ✅ Реализован

**Компоненты:**
- `CurrencyInput` - объединённый компонент ввода суммы + выбор валюты (Uniswap-style)
- `ExchangeRate` - отображение предварительного курса из кэша Redis
- `RateTypeSelector` - выбор типа курса (фиксированный/плавающий)

**Особенности:**
- Предварительный расчёт использует кэшированные курсы из Redis (быстро, без аутентификации)
- Точный расчёт через `/api/v2/price` - только на экране подтверждения
- Disclaimer: "Точный курс будет рассчитан при подтверждении"

##### 5. Панель действий
**ID:** `ACTION_PANEL`

**Кнопка "Назад" (Secondary)**
- Возвращает к редактированию формы
- Сохраняет все введенные данные

**Кнопка "Подтвердить и продолжить" (Primary)**
- Только при активированном чекбоксе согласия
- Создает ордер в FixedFloat API
- Переходит к странице оплаты

#### Визуальные состояния

**1. Готово к подтверждению**
- Все данные отображены
- Чекбокс неактивен
- Кнопка подтверждения disabled

**2. Согласие получено**
- Чекбокс активирован
- Кнопка подтверждения становится активной
- Цветовая подсветка итоговой суммы

**3. Загрузка создания ордера**
- Кнопка показывает spinner
- Все интерактивные элементы disabled
- Показывается статус "Создаем ордер..."

**4. Ошибка создания**
- Кнопка возвращается в исходное состояние
- Показывается сообщение об ошибке
- Предложение "Попробовать снова"

### Известные проблемы
1. `mockTelegramEnv` требует специфический формат `launchParams` - нужно исследовать
2. Приложение не работает вне Telegram без mock окружения

### Технический долг
1. Типизация API ответов может быть улучшена
2. Некоторые компоненты можно разбить на более мелкие
3. CSS можно мигрировать на CSS Modules или styled-components

### Зависимости для обновления
- Следить за обновлениями @tma.js/sdk-react
- React 19 (когда станет стабильным)
